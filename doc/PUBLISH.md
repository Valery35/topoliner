# Публикация выпусков Topoliner

Порядок общий для линейки, навык помощника `publish-release`. Тексты
объявлений лежат в `site/posts_<номер>.md` и `site/posts_<номер>_social.md`.

Площадки Topoliner отличаются от площадок PlanetX.

- Telegram @qgis_isolines - пост приходит сам, ботом по выпуску GitHub.
- ВК - пост на стене vk.ru/qgismodules.
- OSGeo Discourse - своя тема в разделе General, ответы в ней.
- Форум OSM недоступен. 5 ноября 2026 года вход показал блокировку
  учётной записи с пометкой SPAM.
- Форум Rust, AlternativeTo, winget - только для PlanetX Lite.
- linux.org.ru - не больше двух новостей в сутки на учётную запись.
- Reddit - публикует автор, тексты в `_social.md`.
