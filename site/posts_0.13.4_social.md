# Topoliner 0.13.4, тексты для площадок

## Выпуск GitHub

Topoliner 0.13.4

- Диалоги инструментов целиком переведены на английский. Подсказки к полям, варианты в списках и фильтр текстового отчёта раньше выводились по-русски при английском интерфейсе QGIS.
- Подсказка появилась у каждого поля каждого диалога, включая входные и выходные слои.
- Руководства и справки инструментов выверены и пересобраны.

Установка - QGIS, «Модули - Установить из ZIP», файл `topoliner.zip`, или из каталога модулей QGIS.

## Русский пост (ВК, Telegram, Facebook)

Topoliner 0.13.4 - модуль QGIS для топологии полигональных и линейных покрытий.

Что нового.
- Диалоги инструментов целиком на английском при английском интерфейсе QGIS. Раньше подсказки к полям и варианты в списках оставались русскими.
- У каждого поля каждого диалога есть подсказка, в том числе у входных и выходных слоёв.
- Руководства и справки выверены.

Модуль работает в QGIS 3.16 и новее, включая QGIS 4. Он бесплатный и открытый, лицензия GPL 3.

Каталог QGIS - https://plugins.qgis.org/plugins/topoliner/
Выпуск и исходники - https://github.com/Valery35/topoliner/releases/tag/0.13.4

## Английский пост (LinkedIn)

Topoliner 0.13.4, a QGIS plugin for the topology of polygon and line coverages.

What is new.
- Tool dialogs are fully in English when QGIS runs in English. Field hints and option lists used to stay in Russian.
- Every field of every dialog has a hint, input and output layers included.
- The manuals and the tool help were revised.

Works in QGIS 3.16 and later, including QGIS 4. Free and open source, GPL 3.

QGIS plugin repository - https://plugins.qgis.org/plugins/topoliner/
Release and source - https://github.com/Valery35/topoliner/releases/tag/0.13.4
