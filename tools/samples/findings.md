# Образец находок

Первая строка без нарушений.
Вторая строка с длинным тире — вот оно.
Третья строка; с точкой с запятой.
Четвёртая строка: двоеточие внутри.

Пятая строка про софт и кучку данных.
Шестая говорит прямо о деле.
Седьмая называет число объектов.
Восьмая перечисляет: первое, второе, третье.
