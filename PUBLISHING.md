# Публикация Topoliner 0.2.0

Проверка готовности:

```
python tools/preflight.py
python tools/check_docs.py
```

Имя плагина после публикации не меняется, поэтому скрипта переименования
в наборе больше нет: он был нужен один раз, до подачи в каталог.

Скрипт смотрит то же, на что смотрит модератор каталога: заполненность
метаданных, структуру, лицензию, отсутствие внешних зависимостей. Сейчас
он проходит без замечаний.

## Шаг 1. Репозиторий на GitHub

Архив `topoliner-repo.zip` распаковать в `c:\Dev`. Получится `c:\Dev\topoliner`,
папка плагина уровнем ниже.

Создать на GitHub пустой репозиторий `topoliner` без файлов, затем через
GitHub Desktop: **Add - Add existing repository**, указать `c:\Dev\topoliner`,
опубликовать.

Из командной строки то же самое:

```
git init
git add .
git commit -m "Topoliner 0.2.0"
git branch -M main
git remote add origin https://github.com/Valery35/topoliner.git
git push -u origin main
```

Тесты в CI настроены: `.github/workflows/tests.yml` прогоняет их на Python 3.9
и 3.12 при каждом push, настройки не нужны.

## Шаг 2. Релиз на GitHub

Собрать архивы и создать релиз с тегом `v0.2.0`:

```
python tools/build_zip.py
```

- `topoliner.zip` - рабочий, с тестами,
- `topoliner_upload.zip` - для каталога, без тестов.

Релиз стоит сделать до подачи в каталог: пока идёт модерация, плагин можно
поставить из ZIP по прямой ссылке.

## Шаг 3. Каталог plugins.qgis.org

1. Учётная запись OSGeo, если её ещё нет:
   https://www.osgeo.org/community/getting-started-osgeo/osgeo-userid/
2. Войти на https://plugins.qgis.org и загрузить `topoliner_upload.zip`.
3. Дождаться модерации. Первая версия проходит проверку вручную.

Ссылка repository в метаданных должна открываться к моменту подачи,
поэтому шаг 1 идёт раньше.

## Что стоит сказать в анонсе

Инструмент вырос из ручной процедуры: снап слоя к самому себе с допуском,
затем объединение без атрибутов, затем разглядывание результата. Процедура
известная и повторяемая, и каждый раз выполняется руками.

Цифры из проверки на реальных данных:

- слой полигонов кригинга, 252 объекта: 68 вершин лежали точно на рёбрах
  соседей без узла, после вставки узлов проверка не находит ничего,
  суммарная площадь не изменилась;
- слой геомеханических зон, 379 объектов: проверка целиком давала 166 находок,
  с группировкой по пласту 41, три четверти были межпластовыми наложениями;
- упрощение с допуском 5 на слое зон: независимое даёт 46 перекрытий и 25 щелей,
  топологическое не даёт ни одного.
